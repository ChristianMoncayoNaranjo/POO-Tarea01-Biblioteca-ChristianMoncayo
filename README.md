## Descripción
Este proyecto implementa un sistema de gestión de biblioteca utilizando Programación Orientada a Objetos en Python.

El sistema permite:
- Registrar libros
- Registrar estudiantes
- Realizar préstamos
- Devolver libros
- Consultar préstamos activos

## Estructura del proyecto

- modelo/: Contiene las clases del sistema
- diagramas/: Contiene el diagrama UML en PlantUML
- main.py: Programa principal
